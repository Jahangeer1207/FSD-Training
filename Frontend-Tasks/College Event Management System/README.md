# College Event Management System

A responsive web application developed using HTML, CSS, JavaScript, and Bootstrap for managing college events. Students can view upcoming events, register online, check event schedules, browse galleries, and contact event coordinators.

---

## Project Overview

The College Event Management System is designed to simplify the management of technical and cultural events conducted by CVR College of Engineering. The platform provides students with complete event information and an easy registration process.
