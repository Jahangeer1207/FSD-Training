# Online Course Registration Portal

A responsive web application developed using HTML, CSS, JavaScript, and Bootstrap for managing online course registrations. The portal allows students to explore courses, register online, learn about the institute, and contact the administration.

---

## Project Overview

The Online Course Registration Portal is designed for a training institute to provide course information and enable students to register online. The project demonstrates the use of Bootstrap components, responsive web design, and form handling.

---

## Features

### Home Page

* Responsive Navigation Bar
* Hero Carousel Section
* Featured Courses Section
* Student Testimonials
* Footer with Contact Information

### Courses Page

* Course Listings
* Bootstrap Cards
* Course Details Modal
* Responsive Grid Layout

### Registration Page

* Student Registration Form
* Course Selection
* Resume Upload
* Terms & Conditions
* Success Alert Message

### About Us Page

* Institute History
* Vision & Mission
* Faculty Information Cards
* Statistics Section

### Contact Us Page

* Contact Form
* Contact Information
* Google Map Placeholder
* Success Alert Message
