# Personal Portfolio Website

A professional and responsive portfolio website developed using HTML, CSS, JavaScript, and Bootstrap. The portfolio showcases personal information, technical skills, projects, achievements, and contact details.

---

## Project Overview

This portfolio website serves as a digital resume and personal branding platform. It highlights educational background, technical expertise, project experience, achievements, and provides a way for visitors to connect.

---

## Features

### Home Section

* Profile Photo
* Name and Designation
* Short Introduction
* Resume Download Button

### About Me Section

* Educational Details
* Career Objective
* Personal Interests

### Skills Section

* Technical Skills
* Bootstrap Progress Bars

### Projects Section

### Achievements Section
